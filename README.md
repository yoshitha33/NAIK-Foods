# Naik Foods — Authentic Maharashtra. Delivered to Your Door.

A modern, high-conversion, production-quality MERN Stack e-commerce platform built for **Naik Foods**, an authentic regional food brand in Maharashtra, India.

---

## 🌟 Features Overview

- **Brand Identity & Aesthetics**: Designed following the 60–30–10 color rule (60% Warm Neutral `#FFF8F0`, 30% Primary Action Orange `#F28C28`, 10% Regional Fresh Green `#2E7D32`).
- **Dynamic Free Delivery Bar**: Interactive threshold calculator (`₹720 / ₹999 — ₹279 away from FREE shipping!`) with smooth animated progress bar.
- **Smart Recommendation Engine**: Rule-based cross-selling ("You May Also Like", "Frequently Bought Together", "Basket Fillers").
- **Predictive Search**: Real-time debounced autocomplete search bar with instant product & category suggestions.
- **Multi-Step Checkout**: Full support for both **Guest Purchasing** (no registration wall) and Logged-In saved address checkout.
- **Razorpay Payment Integration**: Full client-server architecture with server-side signature verification & local fallback.
- **Track Live Order**: Public order tracker using Order ID + Mobile number with visual 5-step progress bar.
- **SEO & Recipe Content Funnel**: High-converting blog articles guiding readers directly into product purchases.
- **1-Click Reorder / Buy Again**: Specialized account section for quick repeat purchases of daily snacks.
- **Store Locator**: Internal store finder with direct Google Maps navigation links.
- **Festival & Corporate Gifting**: Royal Maharashtra gift box hampers.

---

## 🛠️ Technology Stack

- **Frontend**: React 18, Vite, Tailwind CSS v4, Framer Motion, Lucide React, React Router v6, Axios, React Hook Form.
- **Backend**: Node.js, Express.js REST API, Mongoose, MongoDB, JWT Authentication, bcryptjs password hashing.

---

## 🚀 Installation & Running

### 1. Backend Server Setup

```bash
cd server
npm install
npm run seed     # Populate MongoDB database with authentic Maharashtrian dataset
npm run dev      # Runs Express server on http://localhost:5000
```

### 2. Frontend Client Setup

```bash
cd client
npm install
npm run dev      # Runs Vite dev server on http://localhost:3000
```
